<h2>REQUEST</h2>
Built two custom desktop PCs from individual components: one for me, one for my son. Goal was to hand-select and assemble every part myself rather than buying a pre-built.
<br />

<h2>RESOLUTION</h2>
Sourced and assembled all components for both builds, including CPU, motherboard, RAM, GPU, storage, PSU, and cooling. Installed the OS, updated drivers, and verified all hardware was recognized correctly in BIOS/UEFI before final setup. Confirmed stability and performance post-build using system monitoring tools.
<h2>Components Used</h2>

- <b>CPU:</b> Intel Core i9 [12900k]
- <b>RAM:</b> 32GB [Vengeance DDR5 6000MHz]
- <b>GPU:</b> RTX 3070 [MSI]
- <b>Motherboard:</b> [PRO Z690-A WIFI]
- <b>Storage:</b> [Intel SSDPEKNW010T8]

<h2>Environments Used </h2>

- <b>Windows 11 Home</b> (25H2)
